# Prompt: δημιουργία της απλής έκδοσης (`index.html`)

Δώσε το παρακάτω κείμενο σε νέα συζήτηση με το Claude (Claude Code ή claude.ai). Είναι γραμμένο ώστε να ξεκινήσει σωστά την κατασκευή: πρώτα προδιαγραφές και πυρήνας, μετά οι λειτουργίες σε φάσεις. Η πλήρης εφαρμογή χτίστηκε σε πολλές συζητήσεις· αυτό το prompt δίνει τη βάση και τη σειρά.

---

```text
Θέλω να φτιάξεις μια εφαρμογή web για εκπαιδευτικούς Γυμνασίου και Λυκείου (κυρίως
φυσικών επιστημών / ΕΚΦΕ), που συντάσσουν φύλλα εργασίας απευθείας στον browser.
Όνομα: «Σύνταξη φύλλων εργασίας», υπότιτλος «Γυμνάσιο & Λύκειο».

## Βασικοί περιορισμοί
- Ένα μόνο αρχείο: syntaxi-fyllon-ergasias/index.html, με όλο το CSS, τη JavaScript και
  τις βιβλιοθήκες ενσωματωμένες (σε μπλοκ με σήμανση /* === LIBRARY: όνομα === */).
  Μέγεθος κάτω από 4 MB.
- Λειτουργεί με διπλό κλικ (file://) και από GitHub Pages, χωρίς internet και χωρίς
  διακομιστή. Δεν στέλνει δεδομένα πουθενά.
- Vanilla JavaScript (ES2020), χωρίς build για τον χρήστη. Όλο το UI στα ελληνικά.
- Βιβλιοθήκες σε σταθερές εκδόσεις: KaTeX 0.16.11 (με τις γραμματοσειρές του ως
  data URI), Chart.js 4.4.7, jsPDF 2.5.2, html2canvas 1.4.1, docx 8.6.0,
  qrcode-generator 1.4.4.
- Ασφάλεια: όλο το HTML που μπαίνει στο έγγραφο περνά από sanitizer (επιτρεπόμενο
  υποσύνολο ετικετών και ιδιοτήτων). Iframes μόνο από την εφαρμογή, με sandbox, μόνο https.
- Desktop πρώτα, tablet ως εναλλακτική. Σκοτεινό θέμα. Χωρίς gradients και βαριές
  σκιές.

## Μοντέλο εργασίας
Πρώτα ορίζεις τη δομή του φύλλου σε ενότητες (τίτλος, τύπος: κείμενο, πίνακας, εικόνα,
μαθηματικά, μικτό, γράφημα, υποχρεωτική ή όχι) και μετά γράφεις το περιεχόμενο κάθε
ενότητας στον δικό της επεξεργαστή (contenteditable). Οι ενότητες αναδιατάσσονται με
σύρσιμο, συμπτύσσονται, κρύβονται και αντιγράφονται.

Διάταξη: επικεφαλίδα (τίτλος φύλλου, Άνοιγμα, Αποθήκευση, Προεπισκόπηση, Εξαγωγή),
αριστερό πάνελ με καρτέλες (Πρότυπο, Ενότητες, Εργαλεία, Μορφοποίηση), κεντρική στήλη με
την κάρτα «Στοιχεία εγγράφου» (σχολείο, εκπαιδευτικός, μάθημα, τάξη, ημερομηνία, πεδία
στοιχείων μαθητή) και τις κάρτες ενοτήτων, γραμμή κατάστασης.

## Αρχιτεκτονική
Modules σε IIFE που επικοινωνούν με γεγονότα (CustomEvent με πρόθεμα worksheet:):
Util, Bus, Storage, Prefs, Sanitizer, Toast, Modal, AppState (κεντρική κατάσταση,
immutable κατά σύμβαση, με κανονικοποίηση κάθε εισόδου), TemplateManager,
TemplateLibrary, EditorManager, InsertTools, Formulas, MathEngine, ChemEngine,
GraphEngine, DrawEngine, Quiz, Embeds, ExportManager, ImportManager, Autosave,
UIController.

Κατάσταση: { version, templateName, template: [Section], content: {id: html},
graphs: {id: Graph}, metadata, style }. Αρχείο έργου .json:
{ app: 'worksheet-forge', version, savedAt, state }. Αυτόματη αποθήκευση στο localStorage
(worksheetforge_autosave) κάθε 30″.

## Λειτουργίες, με σειρά υλοποίησης
1. Πυρήνας: ενότητες, επεξεργαστής (έντονα, πλάγια, εκθέτες/δείκτες, επικεφαλίδες,
   λίστες, λίστα ελέγχου, στοίχιση, αναίρεση 50 βημάτων ανά ενότητα), καθαρή επικόλληση
   από Word, αυτόματη αποθήκευση, άνοιγμα και αποθήκευση έργου.
2. Έτοιμα πρότυπα: Εργαστηριακό Φύλλο ΕΚΦΕ, Φύλλο Θεωρίας, Φύλλο Ασκήσεων (με
   «+ Προσθήκη Άσκησης» και ενότητα «Λύσεις» που εξαιρείται από την εξαγωγή), Κενό.
   «Τα πρότυπά μου» ως αρχεία .json σε φάκελο του χρήστη (File System Access API, με
   λήψη αρχείου ως εναλλακτική).
3. Πίνακες: οπτικός επιλογέας έως 20×20, μενού με δεξί κλικ (γραμμές, στήλες,
   συγχώνευση, διαίρεση κελιού, χρώματα, διχρωμία, κλείδωμα κελιών), αλλαγή πλάτους και
   ύψους με σύρσιμο.
4. Τύποι σε κελιά όπως στο Excel (=B2*C2, SUM, AVERAGE, MIN, MAX, ROUND, SQRT, POWER, ^,
   ελληνικά ονόματα, ορίσματα με ;), κλικ για αναφορές, λαβή συμπλήρωσης, δεκαδικά για
   όλο το φύλλο. Αυτόνομη συνάρτηση formulaCore, ώστε να μπαίνει και στο εξαγόμενο HTML.
5. Μαθηματικά KaTeX (Ctrl+M) με ζωντανή προεπισκόπηση, σύμβολα και αγαπημένες
   εξισώσεις.
6. Εικόνες (μικραίνουν αυτόματα στα 1600 px, περικοπή, περιστροφή, αναδίπλωση κειμένου),
   πεδία απάντησης μαθητή (πλαίσιο με γραμμές ή κενό μέσα στη γραμμή), πλαίσια
   (Σημείωση, Tip, Προσοχή, Ορισμός, Θυμήσου), στήλες, σύνδεσμοι, αλλαγή σελίδας.
7. Γραφικές παραστάσεις (Chart.js): από πίνακα του φύλλου ή από δεδομένα, προσαρμογή
   γραμμική, ανάλογη, πολυωνυμική και εκθετική, μπάρες σφάλματος, R², f(x). Το γράφημα
   μπαίνει ως εικόνα και ξαναεπεξεργάζεται με διπλό κλικ.
8. Εξαγωγές:
   - Εκτύπωση (A4) και PDF με jsPDF + html2canvas (σελιδοποίηση που δεν κόβει γραμμές
     πινάκων, μία ενότητα ανά σελίδα),
   - DOCX με docx.js,
   - Διαδραστικό HTML για τον μαθητή: συμπληρώνει πεδία και κελιά, οι τύποι
     υπολογίζονται, οι απαντήσεις μένουν στον browser του, και κατεβάζει PDF με τις
     απαντήσεις του,
   - Προεπισκόπηση με επιλογές (κεφαλίδα, αρίθμηση, QR code για κάθε σύνδεσμο).
9. Μορφοποίηση τελικού φύλλου: έτοιμα στυλ (Κλασική, ΕΚΦΕ, Σύγχρονη, Λιτή), γραμματοσειρά,
   χρώματα, μορφή τίτλων, λογότυπο (και στην κεφαλίδα κάθε σελίδας), προσανατολισμός,
   περιθώρια, ενότητες ως καρτέλες σε πλέγμα.
10. Προχωρημένα:
   - εισαγωγή .odt/.docx σε ενότητες,
   - χημικές εξισώσεις με πρόβλεψη προϊόντων και ισοστάθμιση,
   - ερωτήσεις αυτοαξιολόγησης (πολλαπλής επιλογής, Σωστό/Λάθος, με ανατροφοδότηση στο
     HTML),
   - εργαλείο σχεδίου (σχήματα, βέλη, ελατήριο, κυκλώματα, χάρακας, μοιρογνωμόνιο, snap),
   - ενσωματώσεις (YouTube, PhET, GeoGebra, Desmos, Google),
   - φωνητική πληκτρολόγηση στα ελληνικά.

## Παραδοτέα και τρόπος δουλειάς

  αρχιτεκτονική, μοντέλο δεδομένων, τι ΔΕΝ γίνεται) και περίμενε έγκριση πριν από
  τον κώδικα.

- README.md στα ελληνικά, γραμμένο για εκπαιδευτικούς (γρήγορη αρχή, λειτουργίες,
  συντομεύσεις).
- Σε κάθε φάση δοκίμασε την εφαρμογή σε headless Chromium (φόρτωση χωρίς σφάλματα,
  βασική ροή, εξαγωγές) και πες μου τι δοκιμάστηκε.
- Commit μόνο στο branch που θα σου ορίσω.
```

### Συμβουλές χρήσης

- **Σε φάσεις:** σε μία συζήτηση δεν χωράει όλη η εφαρμογή. Μετά την πρώτη φάση συνέχισε με «Συνέχισε με τη φάση 4…», ή άνοιξε νέα συζήτηση με το SPEC.md και το README.md ως αφετηρία.
- **Με αναφορά στο υπάρχον:** για ίδιο αποτέλεσμα με το τωρινό αρχείο, δώσε το SPEC.md του έργου ως συνημμένο και γράψε «Ακολούθησε αυτό το SPEC».
