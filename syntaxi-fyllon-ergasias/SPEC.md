# Spec: Σύνταξη φύλλων εργασίας (WorksheetForge)

Tags: #φυσική #εκφε #λύκειο #γυμνάσιο

Τρέχουσα κατάσταση της εφαρμογής, όπως είναι υλοποιημένη (as-built). Ξεκίνησε από το αρχικό spec «WorksheetForge» και εμπλουτίστηκε με όσα ζητήθηκαν στη συνέχεια. Οι αποκλίσεις από το αρχικό spec σημειώνονται στο §11.

---

## 1. Τίτλος έργου

**Σύνταξη φύλλων εργασίας** — εργαλείο σύνταξης φύλλων εργασίας για εκπαιδευτικούς

- Υπότιτλος UI: *«Γυμνάσιο & Λύκειο»*
- Εσωτερικό όνομα: `worksheet-forge` (πεδίο `app` στα αρχεία JSON, κλειδιά `worksheetforge_*` στο localStorage)
- Έκδοση: `v1.0.0` (meta `generator`)
- Παραδοτέο: `syntaxi-fyllon-ergasias/index.html`, ένα αυτόνομο αρχείο HTML περίπου 2,28 MB
- Διαδικτυακή έκδοση: https://claude.ai/artifact/92wvuBZcerU1CoQzCaG2hV
- Favicon: SVG με μολύβι πάνω σε έγγραφο, χρώμα `#2563EB`

## 2. Σκοπός

- **Κύριος στόχος:** ο εκπαιδευτικός ορίζει τη δομή του φύλλου σε ενότητες και για κάθε ενότητα παίρνει δικό της επεξεργαστή πλούσιου κειμένου (template-first).
- **Εργαλεία STEM:** εξισώσεις LaTeX, πίνακες, γραφικές παραστάσεις με καμπύλες προσέγγισης, διατάξεις σε στήλες, πλαίσια περιεχομένου, λίστες ελέγχου και ενσωματώσεις (προσομοιώσεις, βίντεο).
- **Επαναχρησιμοποίηση:** πρότυπα με ή χωρίς περιεχόμενο, αποθηκευμένα ως αρχεία `.json` σε φάκελο του χρήστη, και μετατροπή υπαρχόντων φύλλων `.odt` / `.docx` σε επεξεργάσιμα πρότυπα.
- **Παραδοτέα φύλλου:** εκτύπωση, PDF, DOCX και διαδραστικό HTML που ο μαθητής συμπληρώνει στην οθόνη.
- **Offline:** λειτουργεί με διπλό κλικ (`file://`), χωρίς server και CDN. Το δίκτυο χρειάζεται μόνο για τη φωνητική πληκτρολόγηση και για το περιεχόμενο των ενσωματώσεων.

## 3. Κοινό-στόχος

### Πρωτεύον κοινό: εκπαιδευτικοί
- Φυσικών Επιστημών, Μαθηματικών, Χημείας και Βιολογίας σε Γυμνάσιο και Λύκειο.
- Συντάκτες φύλλων ΕΚΦΕ.
- Μέτρια τεχνική εξοικείωση. Συχνά εργάζονται χωρίς σταθερό internet.

### Δευτερεύον κοινό: μαθητές
- Παίρνουν το τελικό PDF/DOCX ή το διαδραστικό HTML, το οποίο συμπληρώνουν στην οθόνη, τσεκάρουν κουτάκια και κατεβάζουν ως PDF με τις απαντήσεις τους.

### Τεχνικό προφίλ
- Browser: Chrome/Edge (πλήρης υποστήριξη, μαζί με φάκελο προτύπων και υπαγόρευση), Firefox, Safari.
- Συσκευή: κυρίως desktop/laptop, και tablet ως εναλλακτική.
- Χωρίς λογαριασμό και χωρίς cloud.

## 4. Τεχνολογία & Constraints

### Stack
- Vanilla JavaScript (ES2020+), HTML5, CSS3. Κανένα framework.
- Ένα αρχείο HTML: inline `<style>`, κάθε βιβλιοθήκη σε δικό της `<script>` και ο κώδικας της εφαρμογής σε τελευταίο `<script>`.
- Επεξεργαστής: `contenteditable` + `document.execCommand` (`styleWithCSS=false`, `defaultParagraphSeparator=p`), με δικό του ιστορικό αναίρεσης και Selection API.

### Βιβλιοθήκες (ενσωματωμένες, σταθερές εκδόσεις)
| Βιβλιοθήκη | Έκδοση | Χρήση |
| --- | --- | --- |
| KaTeX (+ auto-render) | 0.16.11 | Μαθηματικά. Οι γραμματοσειρές woff2 είναι ενσωματωμένες ως data URI |
| Chart.js | 4.4.7 | Γραφικές παραστάσεις |
| jsPDF | 2.5.2 | PDF (προηγμένο) |
| html2canvas | 1.4.1 | Απόδοση σελίδων για το PDF |
| docx | 8.6.0 | DOCX. Browser build, συμπιεσμένο με terser |
| qrcode-generator | 1.4.4 | QR codes για τους συνδέσμους (μαζί με την υποστήριξη UTF-8), συμπιεσμένο με terser |

### Constraints
- Καμία εξωτερική κλήση για τη λειτουργία της εφαρμογής: κανένα `fetch`/XHR, κανένα CDN. Εξωτερικά φορτώνονται μόνο τα iframes των ενσωματώσεων, και μόνο αν τα εισαγάγει ο χρήστης.
- Λειτουργεί με `file://`, σε GitHub Pages και ως Artifact στο claude.ai.
- Στον κώδικα της εφαρμογής δεν υπάρχουν inline σχόλια. Η τεκμηρίωση γίνεται μόνο με JSDoc πάνω από συναρτήσεις και modules.
- Κάθε HTML που προέρχεται από τον χρήστη ή από αρχείο περνά από τον `Sanitizer` πριν μπει στο DOM.

### Build (εργαλείο του συντάκτη, όχι απαίτηση για τον χρήστη)
- Οι πηγές είναι χωριστά αρχεία: `core.js`, `state.js`, `library.js`, `editor.js`, `embed.js`, `math.js`, `graph.js`, `export.js`, `import.js`, `ui.js`, `app.css`, `body.html`. Το `tools/build.py` τα συνενώνει σε ένα HTML.
- Το build:
  - ενσωματώνει τις γραμματοσειρές του KaTeX σε base64,
  - διαφεύγει τα `</script` και `<!--` μέσα στις βιβλιοθήκες,
  - διαφεύγει τον χαρακτήρα U+FFFD ως `�`,
  - αφαιρεί τα sourceMappingURL.
- Με `--artifact` παράγει την έκδοση για claude.ai, χωρίς doctype/html/head/body/meta και με τον `<title>` πρώτο.

## 5. Οπτικό αποτέλεσμα / Layout

### Γενική αισθητική
Ανοιχτό minimalist UI με σκοτεινό θέμα. Γραμματοσειρά UI `Inter` (με system fallback). Το περιεχόμενο εμφανίζεται με τη γραμματοσειρά του εγγράφου (προεπιλογή Georgia).

### Διάταξη (3 ζώνες + statusbar)
```
┌──────────────────────────────────────────────────────────────────────┐
│ HEADER 56px: λογότυπο εφαρμογής | Τίτλος φύλλου | Άνοιγμα, Αποθήκευση, │
│ Προεπισκόπηση, Εξαγωγή ▾ (Εκτύπωση/PDF, PDF προηγμένο, DOCX, HTML),   │
│ θέμα, ?                                                               │
├───────────────────┬──────────────────────────────────────────────────┤
│ LEFT PANEL 280px  │ MAIN                                             │
│ (πτυσσόμενο, ‹ ›) │ ┌ Στοιχεία εγγράφου (σχολείο, εκπαιδευτικός,     │
│ Καρτέλες:         │ │  μάθημα, τάξη, ημερομηνία, πεδία μαθητή)       │
│ Πρότυπο           │ ├ Οθόνη έναρξης «Ξεκίνα με ένα πρότυπο»          │
│ Ενότητες          │ │  (έτοιμα + «Τα πρότυπά μου»)                   │
│ Εργαλεία          │ └ Ενότητες: λίστα (ροή) ή πλέγμα 12 στηλών       │
│ Εμφάνιση          │   (καρτέλες)                                     │
├───────────────────┴──────────────────────────────────────────────────┤
│ STATUSBAR: αυτόματη αποθήκευση · λέξεις/χαρακτήρες ενότητας και       │
│ συνόλου · συμπληρωμένες ενότητες · λειτουργία                         │
└──────────────────────────────────────────────────────────────────────┘
```

### Καρτέλες αριστερού πάνελ
- **Πρότυπο:**
  - έτοιμα πρότυπα και «Τα πρότυπά μου»,
  - εισαγωγή εγγράφου (.odt, .docx),
  - φάκελος προτύπων (ορισμός, επανασύνδεση, άνοιγμα αρχείων),
  - «Με περιεχόμενο και εμφάνιση», όνομα και αποθήκευση προτύπου,
  - εξαγωγή/εισαγωγή προτύπου JSON,
  - «Νέο φύλλο από πρότυπο…».
- Ο τίτλος «Σύνταξη φύλλων εργασίας» πάνω αριστερά είναι κουμπί νέου φύλλου. Αν το τρέχον έχει περιεχόμενο, ρωτά: «Αποθήκευση και νέο» (αρχείο .json, και μόνο αν αποθηκευτεί όντως), «Χωρίς αποθήκευση», «Ακύρωση». Το ίδιο κάνει και το «Νέο φύλλο από πρότυπο…».
- **Ενότητες:**
  - νέα ενότητα (τίτλος, τύπος, υποχρεωτική),
  - προβολή ενοτήτων «Λίστα» ή «Καρτέλες»,
  - λίστα ενοτήτων με σύρσιμο, μετονομασία, σύμπτυξη και διαγραφή,
  - «+ Προσθήκη Άσκησης» στο Φύλλο Ασκήσεων.
- **Εργαλεία:**
  - ενεργή ενότητα,
  - εισαγωγή: Μαθηματικά, Γραφική παράσταση, Πίνακας, Εικόνα, Σύνδεσμος, Αλλαγή σελίδας,
  - παλέτα συμβόλων, αγαπημένες εξισώσεις, γραφήματα του φύλλου.
- **Εμφάνιση:**
  - στυλ, γραμματοσειρά, μέγεθος, χρώμα έμφασης, χρώμα κεφαλίδων πινάκων,
  - μορφή τίτλων ενοτήτων, στοίχιση τίτλου,
  - λογότυπο (θέση, πλάτος), προσανατολισμός, περιθώρια, προεπισκόπηση.

### Κάρτα ενότητας (editor block)
- Κεφαλίδα:
  - λαβή συρσίματος, αριθμός, επεξεργάσιμος τίτλος, τύπος,
  - ένδειξη υποχρεωτικής/προαιρετικής,
  - μάτι (απόκρυψη όλης της ενότητας από το τελικό φύλλο και τις εξαγωγές), «Τ» (απόκρυψη μόνο του τίτλου), σύμπτυξη ▾, εστίαση, διαγραφή,
  - σε προβολή καρτελών, επιλογή πλάτους (¼ … όλο).
- Γραμμή εργαλείων ανάλογα με τον τύπο της ενότητας (§7.3), και από κάτω το πεδίο επεξεργασίας.
- Σε προβολή καρτελών υπάρχει λαβή αλλαγής μεγέθους κάτω δεξιά (πλάτος και ελάχιστο ύψος).
- Πλαίσιο κάρτας ανάλογα με την κατάσταση:
  - μπλε όταν η ενότητα είναι ενεργή,
  - κόκκινο όταν είναι υποχρεωτική και κενή,
  - πράσινο όταν έχει συμπληρωθεί.

## 6. Λειτουργίες & Controls

### 6.1 Πρότυπα
- [x] Ενότητες με τίτλο (≤100), τύπο (Κείμενο, Πίνακας, Εικόνα, Μαθηματικά, Μικτό, Γράφημα) και σήμανση υποχρεωτικής.
- [x] Τέσσερα έτοιμα πρότυπα (§10.4). Η οθόνη έναρξης τα προτείνει μαζί με τα πρότυπα του χρήστη.
- [x] Αντίγραφο ενότητας (κουμπί στην κάρτα και στη λίστα): νέα ενότητα ακριβώς από κάτω με τις ίδιες ρυθμίσεις και το ίδιο περιεχόμενο· τα γραφήματα παίρνουν νέο `data-graph-id` με αντίγραφο των δεδομένων τους.
- [x] Αναδιάταξη με σύρσιμο, στη λίστα του πάνελ και στις ίδιες τις κάρτες. Στο πλέγμα η θέση απόθεσης υπολογίζεται σε δύο διαστάσεις.
- [x] Έξυπνη συγχώνευση κατά τη φόρτωση προτύπου: οι ενότητες με ίδιο `id` κρατούν το περιεχόμενό τους. Για ενότητες με περιεχόμενο που αφαιρούνται εμφανίζεται διάλογος: «Διαγραφή» ή «Διατήρηση στο τέλος».
- [x] **Πρότυπα με περιεχόμενο και εμφάνιση:** το πρότυπο αποθηκεύει, προαιρετικά, το αρχικό HTML κάθε ενότητας (`starter`) και το στυλ.
- [x] **Τα πρότυπά μου σε αρχεία:**
  - Ο χρήστης ορίζει φάκελο μέσω File System Access API (Chrome/Edge). Κάθε πρότυπο είναι ένα αρχείο `.json` και ζητείται επιβεβαίωση πριν αντικατασταθεί υπάρχον.
  - Ο browser κρατά μόνο τον δείκτη (handle) του φακέλου, στο IndexedDB `worksheetforge` / `handles` / `templates-folder`.
  - Καταστάσεις φακέλου: `none`, `needs-permission` (με κουμπί επανασύνδεσης), `ready`, `unsupported`.
  - Χωρίς φάκελο (σε Firefox, Safari ή claude.ai) η αποθήκευση γίνεται με λήψη αρχείου και το άνοιγμα με «Άνοιγμα προτύπου από αρχείο…».
  - Παλιά πρότυπα που είχαν μείνει στο localStorage μεταφέρονται σε αρχεία με ένα κλικ.
- [x] Εξαγωγή και εισαγωγή προτύπου σε JSON (§7.2). Η εισαγωγή δέχεται και αρχείο έργου ή σκέτο πίνακα ενοτήτων.
- [x] **Εισαγωγή εξωτερικού φύλλου (.odt, .docx)** ως πρότυπο (§7.6). Τα PDF δεν μετατρέπονται.

### 6.2 Επεξεργαστής (ανά ενότητα)
- [x] Έντονα, πλάγια, υπογράμμιση, διακριτή διαγραφή, εκθέτης, δείκτης.
- [x] Επικεφαλίδες H1–H4 και κανονικό κείμενο. Μέγεθος γραμμάτων 8–36 pt.
- [x] Λίστες με κουκκίδες, αριθμημένες και **λίστες ελέγχου** (κουτάκια που τσεκάρονται με κλικ αριστερά του στοιχείου).
- [x] Στοίχιση, εσοχές, καθαρισμός μορφοποίησης.
- [x] Αναίρεση/επανάληψη έως 50 βήματα ανά ενότητα (στιγμιότυπο μετά από 500 ms αδράνειας).
- [x] **Εισαγωγή παντού:** εικόνες, εξισώσεις, γραφήματα, πίνακες, στήλες, πλαίσια και ενσωματώσεις μπαίνουν στο κελί, στο στοιχείο λίστας, στο πλαίσιο ή στο blockquote όπου βρίσκεται ο κέρσορας. Οι εικόνες παίρνουν το πλάτος του σημείου εισαγωγής.
- [x] **Πίνακες:**
  - επιλογέας διαστάσεων έως 20×20, με ή χωρίς γραμμή κεφαλίδας,
  - μενού δεξιού κλικ με Αποκοπή/Αντιγραφή (αν υπάρχει επιλογή), Επικόλληση (μέσω `navigator.clipboard`: εικόνα, HTML μετά από Sanitizer ή κείμενο· αλλιώς μήνυμα για Ctrl+V), προσθήκη/διαγραφή γραμμών και στηλών, τύπους και γράφημα. Πάνω σε γράμμα κειμένου (έλεγχος με `caretPositionFromPoint`) μένει το μενού του browser για τις προτάσεις ορθογραφίας· Shift+δεξί κλικ δίνει πάντα το μενού του πίνακα,
  - Tab και Shift+Tab για μετακίνηση μεταξύ κελιών (στο τελευταίο κελί προστίθεται γραμμή).
  - κλείδωμα κελιών: `td/th[data-locked="true"]` (ο Sanitizer δέχεται μόνο `true`). Στον επεξεργαστή γίνονται `contenteditable=false` (αφαιρείται κατά τη σειριοποίηση), φαίνονται με διαγράμμιση και 🔒, και το Tab τα προσπερνά. Στο διαδραστικό HTML δεν γίνονται πεδία συμπλήρωσης,
  - χρώματα: `background-color` σε κελιά (κελί, γραμμή, στήλη ή πίνακας) και διχρωμία με κλάση `wf-stripe-rows` / `wf-stripe-cols` και `--wf-stripe` στο `<table>`. Στο DOCX γίνονται shading κελιών· στην εκτύπωση `print-color-adjust: exact`. Το κείμενο σε χρωματιστά κελιά μένει σκούρο και στο σκοτεινό θέμα,
  - διαίρεση κελιού σε έως 10×10: μοιράζει πρώτα τα colspan/rowspan του κελιού και, αν δεν φτάνουν, προσθέτει στήλες/γραμμές και αυξάνει τα span των κελιών που περνούν από εκεί· οι αναφορές τύπων μετατοπίζονται. Συγχώνευση με το δεξί/κάτω κελί όταν έχουν ίδιο ύψος/πλάτος,
  - σύρσιμο ορίων (±4 px): πλάτη στηλών σε `<colgroup><col style="width: N%">` (με `table-layout: fixed`), ύψος γραμμής σε `tr style="height"`. Η προσθήκη/διαγραφή στήλης και η διαίρεση ενημερώνουν τα `<col>`. Στο DOCX γίνονται `columnWidths` και ελάχιστο ύψος γραμμής,
- [x] **Τύποι σε κελιά** (§7.4α):
  - γράφεται `=` και τύπος απευθείας στο κελί (μετατρέπεται με Enter, Tab ή όταν φύγει ο κέρσορας), ή από το μενού δεξιού κλικ «Τύπος υπολογισμού…»,
  - όσο γράφεται τύπος, κλικ σε άλλο κελί του ίδιου πίνακα βάζει την αναφορά του στη θέση του κέρσορα και σύρσιμο βάζει περιοχή· δεύτερο κλικ χωρίς ενδιάμεση πληκτρολόγηση αντικαθιστά την αναφορά. Οι αναφορές του τύπου επισημαίνονται με χρωματιστά πλαίσια σε στρώμα `position: fixed`, χωρίς αλλαγή στο DOM του εγγράφου,
  - όσο γράφεται τύπος, πλαίσιο βοήθειας κάτω από το κελί (ή πάνω, αν δεν χωρά): ζωντανό αποτέλεσμα ή μήνυμα σφάλματος, σύνταξη της συνάρτησης της ανοιχτής παρένθεσης, οδηγίες. `pointer-events: none`· Esc το κλείνει μέχρι να φύγει ο κέρσορας από το κελί,
  - λαβή συμπλήρωσης στη γωνία κελιού με τύπο: σύρσιμο κάθετα ή οριζόντια αντιγράφει τον τύπο μετακινώντας τις σχετικές αναφορές (εκτός από `$`), και αντικαθιστά το περιεχόμενο των κελιών εκτός από εικόνες, πίνακες και εξισώσεις,
  - αναφορές τύπου Excel (`B2`, `B2:B6`, `$B$2`) μέσα στον ίδιο πίνακα· στήλες A, B, C… και γραμμές 1, 2, 3… μετρώντας και την κεφαλίδα,
  - πράξεις `+ − * / ^` (και `× ÷ · ² ³ √`), συναρτήσεις SUM, AVERAGE, PRODUCT, MIN, MAX, COUNT, SQRT, ABS, POWER, ROUND, με ελληνικά συνώνυμα (ΑΘΡΟΙΣΜΑ, ΜΕΣΗ, ΓΙΝΟΜΕΝΟ, ΡΙΖΑ …),
  - διάλογος με γρήγορες πράξεις (Άθροισμα, Μέση τιμή, Πρόσθεση, Αφαίρεση, Γινόμενο, Διαίρεση, Τετράγωνο, Ρίζα) που προτείνουν κελιά, μικρογραφία του πίνακα για κλικ σε κελιά, δεκαδικά ψηφία, ζωντανό αποτέλεσμα και «ίδιος τύπος στα κελιά από κάτω»,
  - ζωντανός επανυπολογισμός· διπλό κλικ σε αποτέλεσμα για επεξεργασία, «Κατάργηση τύπου» κρατά την τιμή ως κείμενο.
- [x] **Στήλες:** διάταξη 2–4 στηλών ως πίνακας διάταξης (`wf-grid`), με ή χωρίς περιγράμματα και τίτλους. Έτοιμες επιλογές:
  - ΕΚΦΕ: Παρατήρηση / Πείραμα / Συμπέρασμα, με γραμμή Tip,
  - Ερώτηση / Απάντηση,
  - Τι ξέρω / Τι θέλω να μάθω / Τι έμαθα,
  - 2, 3 ή 4 στήλες.
- [x] **Πλαίσια περιεχομένου:** Σημείωση, Tip, Προσοχή, Ορισμός, Θυμήσου. Το καθένα έχει χρώμα και αριστερό περίγραμμα, και ο τίτλος του είναι επεξεργάσιμος.
- [x] **Σύνδεσμοι:**
  - διάλογος με URL, κείμενο και στόχο (`_blank` / `_self`),
  - αναδυόμενο παράθυρο με άνοιγμα, επεξεργασία και αφαίρεση,
  - δεκτά μόνο http(s) και mailto· χωρίς σχήμα προστίθεται αυτόματα `https://`.
- [x] Λεζάντα με αυτόματη αρίθμηση («Εικόνα N:») και αλλαγή σελίδας για την εκτύπωση.
- [x] Οριζόντια γραμμή (`<hr>`, Ctrl+Alt+H) στις ενότητες κειμένου και μικτές· στο DOCX γίνεται κάτω περίγραμμα παραγράφου.

### 6.3 Εικόνες και αντικείμενα
- [x] Εισαγωγή από αρχείο, με σύρσιμο ή με επικόλληση. Διάλογος με εναλλακτικό κείμενο (≤300) και λεζάντα. Πάνω από 5 MB εμφανίζεται προειδοποίηση με «Συνέχεια» / «Ακύρωση». Τα WebP/BMP μετατρέπονται σε PNG. Κάθε εικόνα περνά από `Util.shrinkImage(src, 1600)` (λογότυπο: 800): το πολύ 1600 px στη μεγάλη πλευρά, JPEG 0,85 αν δεν έχει διαφάνεια (PNG χωρίς διαφάνεια μένει PNG αν δεν είναι πάνω από 1,5× το JPEG), και κρατιέται η αρχική αν η νέα δεν είναι τουλάχιστον 10% μικρότερη. Τα GIF μένουν ως έχουν.
- [x] **Επιλογή αντικειμένου** (εικόνα, γράφημα, ενσωμάτωση): πλαίσιο με λαβές γωνιών για το πλάτος (σε % του διαθέσιμου πλάτους) και γραμμή εργαλείων που μένει πάντα ορατή. Περιεχόμενα της γραμμής:
  - πέντε θέσεις: αριστερά με αναδίπλωση, αριστερά, κέντρο, δεξιά, δεξιά με αναδίπλωση,
  - πλάτος 25 / 50 / 75 / 100 %,
  - για εικόνα: περικοπή/περιστροφή, εναλλακτικό κείμενο, διαγραφή,
  - για γράφημα: επεξεργασία γραφήματος, εναλλακτικό κείμενο, διαγραφή,
  - για ενσωμάτωση: αλλαγή συνδέσμου, άνοιγμα σε νέα καρτέλα, διαγραφή, και λαβή ύψους στο κάτω μέρος (120–1200 px).
  - Το Delete διαγράφει το επιλεγμένο αντικείμενο.
- [x] **Αναδίπλωση κειμένου:**
  - Υλοποιείται με τις κλάσεις `wf-float-left` / `wf-float-right` (CSS float). Ένα αντικείμενο φαρδύτερο από 60% μικραίνει στο 45%.
  - Η απλή στοίχιση εικόνας ορίζει το `text-align` της παραγράφου της. Για τις ενσωματώσεις χρησιμοποιούνται οι κλάσεις `wf-obj-left` / `wf-obj-right`.
- [x] **Περικοπή και περιστροφή** (διάλογος με canvas):
  - περιστροφή ±90° και κατοπτρισμός ↔ / ↕,
  - ευθυγράμμιση −45°…+45° με βήμα 0,5°,
  - πλαίσιο περικοπής με 8 λαβές και πλέγμα τρίτων, που μετακινείται με σύρσιμο,
  - κουμπιά «Όλη η εικόνα» και «Επαναφορά», ένδειξη τελικού μεγέθους.
  - Η εικόνα επεξεργάζεται έως 2400 px στη μεγάλη πλευρά. Το αποτέλεσμα αποθηκεύεται ως JPEG 0,92 (αν η πηγή ήταν JPEG, με λευκό φόντο) ή αλλιώς ως PNG, και το ποσοστό πλάτους διατηρείται.
  - Η αλλαγή αναιρείται με Ctrl+Z. Δεν είναι διαθέσιμη για γραφήματα.
- [x] **Ενσωματώσεις (iframe)** από απλό σύνδεσμο ή κώδικα `<iframe>`, μέσω του κουμπιού `</>` ή με Ctrl+Alt+E:
  - Δεκτά μόνο `https` (το `http` αναβαθμίζεται σε `https`).
  - Αυτόματη μετατροπή συνδέσμων:
    - YouTube → `youtube-nocookie.com/embed/ID`, με χρόνο έναρξης από `t=` / `start=`,
    - Vimeo → `player.vimeo.com/video/ID`,
    - GeoGebra `/m/ID` → `material/iframe/id/ID/…`,
    - PhET `/<γλώσσα>/simulations/NAME` → `sims/html/NAME/latest/NAME_all.html?locale=el`,
    - Google Docs/Sheets → `preview`, Slides → `embed`, Forms → `viewform?embedded=true`, Drive αρχείο → `preview`,
    - Desmos → `?embed`,
    - οτιδήποτε άλλο ενσωματώνεται όπως είναι.
  - Ο διάλογος έχει σύνδεσμο, ένδειξη αναγνώρισης, τίτλο (συμπληρώνεται αυτόματα), ύψος 240/360/480/600 px και ζωντανή προεπισκόπηση.
  - iframe με `sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox allow-forms allow-presentation"`, `allow` για fullscreen, autoplay, encrypted-media κ.λπ., και `loading=lazy`.
  - Στο claude.ai, όπου η πολιτική ασφαλείας δεν επιτρέπει πλαίσια, εμφανίζεται κάρτα με τον σύνδεσμο.
  - Έντυπη μορφή (εκτύπωση, PDF, DOCX, προεπισκόπηση): σύνδεσμος «↗ τίτλος» με την πλήρη διεύθυνση από κάτω. Το διαδραστικό HTML κρατά το ζωντανό iframe, με τον σύνδεσμο από κάτω.

  - Οι εξισώσεις μπαίνουν ως εικόνες, οπότε η σελίδα δεν χρειάζεται το KaTeX και τις γραμματοσειρές του.
  - Ο κώδικας της σελίδας (`exportRuntime`) και η σελιδοποίηση (`paginate`) περνούν αυτούσια με `Function.prototype.toString()`. Οι ρυθμίσεις του PDF μπαίνουν σε `<script type="application/json" id="wf-pdf-config">`.
  - Αν οι βιβλιοθήκες PDF δεν βρεθούν στην εφαρμογή, το κουμπί γίνεται «Εκτύπωση».
- [x] **Προεπισκόπηση και επιλογές εξαγωγής** (κουμπί Προεπισκόπηση ή Εξαγωγή → «Επιλογές και προεπισκόπηση…»): σελίδες A4 με την ίδια σελιδοποίηση και κουμπιά HTML / DOCX / PDF / Εκτύπωση. Οι επιλογές ισχύουν σε όλες τις εξαγωγές και αποθηκεύονται:
  - στοιχεία εγγράφου, το καθένα με τικ: λογότυπο, σχολείο, τίτλος φύλλου, μάθημα, τάξη, ημερομηνία, εκπαιδευτικός, πεδία στοιχείων μαθητή (το τελευταίο είναι ρύθμιση του φύλλου),
  - αρίθμηση ενοτήτων, λεπτή γραμμή ανάμεσα στις ενότητες (`wf-section-lines`· στο DOCX κάτω περίγραμμα κενής παραγράφου), γραμμές απάντησης σε κενές ενότητες, συμπερίληψη συμπτυγμένων,
  - τίτλοι ενοτήτων (`sectionTitles`) και αρίθμηση (`numbering`) για όλο το φύλλο: χωρίς τικ δεν μπαίνουν σε κανένα εξαγόμενο. Δεν υπάρχει λίστα ανά ενότητα· γι' αυτό μένουν το «Τ» (`hideTitle`) και το «μάτι» (`hidden`) της κάρτας,
  - χωρισμός σε σελίδες (`style.pdfPaging`, το ίδιο με το Εμφάνιση → Σελίδες στο PDF)· το `section` βάζει και `wf-break-before`, οπότε το DOCX παίρνει αλλαγή σελίδας ανά ενότητα (όχι στη διάταξη καρτών· στα PDF και στην προεπισκόπηση ισχύει και εκεί),
  - QR code για κάθε σύνδεσμο (`qrLinks`, προεπιλογή ναι): το `addLinkQrs` βάζει, κάτω από την παράγραφο (ή μέσα στο στοιχείο λίστας, στο κελί, στο πλαίσιο) που έχει συνδέσμους http/https, ένα `div.wf-qr-row` με ένα QR (PNG 22 mm, διόρθωση σφαλμάτων M, λευκό περιθώριο 4 κουτάκια) ανά διαφορετική διεύθυνση, μέσα σε σύνδεσμο, και από κάτω τον τίτλο του συνδέσμου (ή τον τομέα, αν το κείμενο είναι η ίδια η διεύθυνση). Ισχύει σε PDF, Εκτύπωση, προεπισκόπηση και DOCX (εικόνα μέσα σε `ExternalHyperlink`)· όχι στο διαδραστικό HTML, όπου οι σύνδεσμοι ανοίγουν απευθείας,
  - τίτλος, ημερομηνία και αριθμός σελίδας στην κεφαλίδα/υποσέλιδο.
- [x] **Έλεγχος πριν από κάθε εξαγωγή:** λίστα με τις κενές υποχρεωτικές ενότητες και επιλογές «Συνέχεια» / «Επιστροφή για συμπλήρωση».

### 7.4α Τύποι σε κελιά
- Το κελί περιέχει `span.wf-formula[data-formula][data-decimals]` με `contenteditable=false` και το τελευταίο αποτέλεσμα ως κείμενο. Οι εξαγωγές (PDF, DOCX, HTML) βλέπουν απλό κείμενο.
- Αναλυτής αναδρομικής κατάβασης· `-2^2 = -4`. Δεκαδικά με κόμμα ή τελεία, ορίσματα με `;` (ή `,` όταν δεν ακολουθεί ψηφίο, π.χ. `POWER(B2,2)`). Γράμματα στηλών από ελληνικό πληκτρολόγιο αντιστοιχίζονται στο πλήκτρο τους (Ψ→C, Γ→G).
- Χάρτης κελιών με colspan/rowspan. Ο επανυπολογισμός γίνεται σε κάθε συγχρονισμό της ενότητας (300 ms μετά την πληκτρολόγηση) και κατά τη φόρτωση, με προσωρινή μνήμη ανά κελί και εντοπισμό κυκλικών αναφορών.
- Κενά κελιά μετρούν 0 στις πράξεις και παραλείπονται στις συναρτήσεις. Τύπος που όλα τα κελιά του είναι κενά δείχνει κενό (στον επεξεργαστή `ƒx`), ώστε ένα φύλλο με άδειες γραμμές μετρήσεων να μη γεμίζει με 0 ή `#ΔΙΑΙΡ/0!`.
- Σφάλματα: `#ΣΦΑΛΜΑ!` (σύνταξη), `#ΟΝΟΜΑ?`, `#ΑΝΑΦ!`, `#ΤΙΜΗ!` (κείμενο σε πράξη), `#ΔΙΑΙΡ/0!`, `#ΑΡΙΘ!`, `#ΚΥΚΛΟΣ!`. Το μήνυμα φαίνεται ως tooltip.
- Η εισαγωγή/διαγραφή γραμμής ή στήλης μετατοπίζει τις αναφορές όπως το Excel· αναφορά σε διαγραμμένο κελί γίνεται `#ΑΝΑΦ!`. Το «ίδιος τύπος από κάτω» μετατοπίζει τις σχετικές γραμμές και αφήνει τα κελιά με κείμενο.
- Μορφή: δεκαδικά του τύπου (`data-decimals`), αλλιώς η ρύθμιση του φύλλου `style.formulaDecimals` (0–3, πάνελ Εργαλεία → Πίνακες), αλλιώς αυτόματα έως 6 σημαντικά ψηφία· χωρίς διαχωριστικό χιλιάδων. Η αλλαγή της ρύθμισης ξαναϋπολογίζει όλους τους τύπους· το «Ίδια δεκαδικά σε όλους τους τύπους» αφαιρεί τα `data-decimals`.
- Ο πυρήνας (`formulaCore`: ανάλυση, υπολογισμός, μορφοποίηση) είναι αυτόνομη συνάρτηση χωρίς εξαρτήσεις. Το `Formulas` τον χρησιμοποιεί στην εφαρμογή, και το διαδραστικό HTML τον ενσωματώνει (μέσω `toString`, μόνο όταν υπάρχουν τύποι) για να ξαναϋπολογίζει σε κάθε πληκτρολόγηση του μαθητή και κατά τη φόρτωση. Τα κελιά με τύπο δεν γίνονται πεδία συμπλήρωσης.

### 7.5 Εξαγωγή
- **Σελίδες στο PDF** (`style.pdfPaging`: `section` (προεπιλογή) | `breaks` | `flow`· τα παλιά φύλλα με `fitPages` γίνονται `breaks`): το `paginate(root, pageH, 0.65, sections)` κάνει κάθε κομμάτι μία σελίδα, με όρια τις αλλαγές σελίδας και, στο `section`, την αρχή κάθε ενότητας εκτός της πρώτης. Αν το κομμάτι δεν χωρά, `scale = pageH / ύψος` (≥ 0,65) κεντραρισμένο οριζόντια· αλλιώς χωρίζεται κανονικά. Ισχύει στο PDF (προηγμένο), στην προεπισκόπηση (με `transform: scale`) και στο PDF του διαδραστικού HTML. Στην εκτύπωση του browser το `section` γίνεται `break-before: page` και `zoom` ανά ενότητα (όχι στη διάταξη καρτών). Ασφαλή σημεία κοπής: όταν ένα κομμάτι χωρίζεται, το `paginate` μαζεύει τα «άτομα» (παράγραφοι, στοιχεία λίστας, εικόνες, εξισώσεις, κελιά χωρίς εσωτερικά blocks κ.ά.) και μετακινεί κάθε κοπή πάνω από όποιο άτομο θα έκοβε, επαναληπτικά, ώστε σε στήλες ή κάρτες δίπλα-δίπλα να μην κόβεται γραμμή σε καμία στήλη· αν η κοπή θα έπεφτε πάνω από το 25% της σελίδας, κρατιέται η αρχική. Πλάτεμα πριν τη σμίκρυνση (όχι στη διάταξη καρτών): στην αρχή του `paginate`, κάθε ομάδα παιδιών του root ανάμεσα σε όρια σελίδας που δεν χωρά (και δεν έχει `.wf-pagebreak`) παίρνει πλάτος `f × αρχικό` (box-sizing border-box), με το μικρότερο `f` ≤ 1/minScale για το οποίο ύψος(f)/f ≤ pageH (διχοτόμηση, 10 βήματα)· τα υπόλοιπα παιδιά κρατούν το αρχικό πλάτος και ο root πλαταίνει όσο το πλατύτερο. Κάθε σελίδα επιστρέφει `width` (px) και `scale = min(scale, W0 / width)`· τα PDF κόβουν από τον καμβά πλάτος `width` και το τοποθετούν στο πλάτος κειμένου, η προεπισκόπηση με `transform-origin: 0 0`. Στην εκτύπωση του browser το `zoom` κρατά ήδη όλο το πλάτος (το κείμενο ξαναμοιράζεται), οπότε το `fitSectionsForPrint` βρίσκει με διχοτόμηση το μεγαλύτερο zoom (≥ 0,65) που χωρά. Ποιότητα (`print.pdfQuality`: `high` 2× / JPEG 0,92, `normal` 2× / 0,8 (προεπιλογή), `small` 1,5× / 0,72), και στο διαδραστικό HTML μέσω `CFG.quality`. Το `pageSlice` (αυτόνομο, περνά με toString) κόβει κάθε σελίδα από τον καμβά και μικραίνει τις πλατυσμένες στο κανονικό πλάτος, ώστε να έχουν την ίδια ανάλυση με τις άλλες. Το html2canvas καλείται με `ignoreElements` για τα παιδιά του `body` εκτός από τη σκηνή, ώστε να μην αντιγράφει όλη την εφαρμογή (περίπου 40% ταχύτερη εξαγωγή).
- Όλες οι εξαγωγές ξεκινούν από το `buildPrintable(opts)`, που περιέχει:
  - κεφαλίδα (σχολείο, τίτλος, στοιχεία, λογότυπο) και γραμμή στοιχείων μαθητή,
  - τις ενότητες με τις κλάσεις στυλ `wf-st-*` και, όταν χρειάζεται, `wf-layout-grid`,
  - γραμμές απάντησης στις κενές ενότητες,
  - τις ενσωματώσεις → σύνδεσμοι (ή ζωντανά iframe με `liveEmbeds`).
- Το `paginate()` επιλέγει σημεία αλλαγής σελίδας στα όρια στοιχείων:
  - όχι μέσα σε καρτέλες μικρότερες από όλο το πλάτος,
  - όχι μέσα σε αντικείμενα με αναδίπλωση,
  - τηρεί τις αναγκαστικές αλλαγές σελίδας.
- Κάθε εξαγωγή τυλίγεται σε `try/catch` και σε αποτυχία εμφανίζει «Σφάλμα κατά την εξαγωγή: …».

### 7.6 Εισαγωγή ODT/DOCX
- Δικός της αναγνώστης ZIP (`DecompressionStream('deflate-raw')`) και `DOMParser` για τα XML.
- Επιλύει στυλ (έντονα, πλάγια, υπογράμμιση, εκθέτες, στοίχιση, επικεφαλίδες), λίστες, πίνακες με συγχωνεύσεις και εικόνες. Το λογότυπο της κεφαλίδας περνά στην «Εμφάνιση».
- Καθαρισμός πινάκων:
  - πρώτη έντονη γραμμή → `th`,
  - πίνακες δραστηριοτήτων → `wf-grid`,
  - γραμμές «Tip» → `wf-tip`,
  - επικεφαλίδες μέσα σε κελιά → παράγραφοι.
- Χωρισμός σε ενότητες: «Αυτόματος» (επικεφαλίδες και πίνακες-δραστηριότητες), «Στις επικεφαλίδες» ή «Μία ενότητα».
- «Μόνο η δομή»: αδειάζει τις απαντήσεις και κρατά τις κεφαλίδες.
- Ο χρήστης επιλέγει «Νέο φύλλο (αντικατάσταση του τρέχοντος)» ή «Προσθήκη στο τέλος του τρέχοντος φύλλου».

### 7.7 Ασφάλεια (Sanitizer)
- **Επιτρέπονται:**
  - ετικέτες: `p, div, br, span, b, strong, i, em, u, s, strike, del, sub, sup, ul, ol[start], li[data-checked], a[href,target,rel,title], table, thead, tbody, tfoot, tr, td/th[colspan,rowspan ≤20], img[src,alt,data-graph-*], h1–h4, blockquote, hr, pre, code, figure, figcaption, caption, colgroup, col`,
  - περιορισμένο σύνολο ιδιοτήτων CSS, χωρίς `url()`/`expression`,
  - μόνο οι κλάσεις της εφαρμογής.
- **Απορρίπτονται:** `script, style, iframe, object, embed, form, input, svg, math, video, …`.
- **Εικόνες:** μόνο `data:image/(png|jpeg|gif|webp|bmp);base64`. **Σύνδεσμοι:** μόνο `http(s)` / `mailto`, και το `target=_blank` παίρνει `rel=noopener noreferrer`.
- **Τύποι:** από ένα `.wf-formula` κρατιούνται μόνο το `data-formula` (ξεκινά με `=`, ≤300), το `data-decimals` (0–6) και το κείμενο (≤60).
- **Ενσωματώσεις:** από ένα `.wf-embed` κρατιούνται μόνο τα `data-src` / `data-href` (https, ≤2000), `data-title` (≤200), `data-height` (120–1200), το πλάτος σε % (15–100) και οι κλάσεις θέσης. Το iframe δημιουργείται πάντα από την εφαρμογή, ποτέ από αποθηκευμένο HTML.
- Στην επικόλληση αφαιρούνται όλες οι κλάσεις και τα περισσότερα στυλ.

- Σκιές: `sm 0 1px 2px /5%`, `md 0 4px 6px /7%`, `lg 0 10px 25px /10%`, header `0 1px 3px /10%`.
- Μεταβάσεις: 0,15s (hover), 0,2s (πάνελ), 0,3s (διάλογοι), καμία πάνω από 400ms.
- Z-index: πάνελ 50, header 100, πλαίσιο επιλογής αντικειμένου 90, διάλογοι 200, tooltips 300, toasts 400.

### 8.2 Τυπογραφία

## 9. Τι ΔΕΝ γίνεται

### 9.1 Τεχνικά
- Κανένα CDN, κανένα backend, κανένα framework.
- Κανένα `eval`. Κανένα `innerHTML` με δεδομένα χρήστη χωρίς Sanitizer: τα στοιχεία δημιουργούνται με `Util.h()` και `textContent`.
- Στον κώδικα της εφαρμογής δεν υπάρχουν inline σχόλια.
- Οι εγγραφές στο localStorage δεν μπλοκάρουν το UI (`requestIdleCallback`).
- Τα πρότυπα του χρήστη δεν αποθηκεύονται στον browser, παρά μόνο σε αρχεία.

### 9.2 UX
- Επιβεβαίωση ζητείται μόνο για καταστροφικές ενέργειες: διαγραφή ενότητας με περιεχόμενο, φόρτωση προτύπου ή νέο φύλλο με απώλεια περιεχομένου, αντικατάσταση αρχείου προτύπου.
- Οι ενημερώσεις εμφανίζονται ως toasts, ενώ διάλογοι ανοίγουν μόνο όταν χρειάζεται απόφαση του χρήστη.
- Όλο το UI είναι στα ελληνικά.
- Η εφαρμογή σχεδιάστηκε για desktop. Το tablet υποστηρίζεται ως εναλλακτική και η σελίδα δεν κάνει οριζόντια κύλιση.

### 9.3 Αισθητικά
- Χωρίς gradients στο UI και χωρίς βαριές σκιές.
- Χωρίς διακοσμητικά animations.
- Χωρίς custom scrollbars, πέρα από `scrollbar-width: thin`.

## 10. Σημειώσεις υλοποίησης

### 10.1 Κρίσιμες τεχνικές αποφάσεις
- **KaTeX αντί MathJax:** μικρότερο μέγεθος και σύγχρονη απόδοση.
- **Εξισώσεις στο PDF:** αποδίδονται ως PNG μέσω SVG `foreignObject`, μαζί με τα CSS και τις γραμματοσειρές του KaTeX, επειδή το html2canvas δεν αποδίδει σωστά τις γραμμές κλασμάτων και τα SVG. Στο DOCX μπαίνουν ως εικόνες με το LaTeX στο εναλλακτικό κείμενο.
- **Λογότυπο στην κεφαλίδα της εκτύπωσης:** μπαίνει στο `@top-left` ως `content: url(data:image/svg+xml…)`. Είναι SVG με διαστάσεις σε mm που περιέχει την εικόνα σε πλήρη ανάλυση, και φορτώνεται εκ των προτέρων με κρυφό `<img>`. Το `background` δεν τυπώνεται χωρίς «Γραφικά φόντου», και το `content: url(PNG)` δεν επιτρέπει να οριστεί μέγεθος.
- **Λειτουργία Artifact** (`window.claude.use` υπάρχει):
  - οι λήψεις γίνονται με `claude.use('downloads').save()`,
  - η «Εκτύπωση» γίνεται PDF (προηγμένο),
  - δεν υπάρχουν φάκελος προτύπων, υπαγόρευση και ζωντανά iframes.
- **UUID:** `crypto.randomUUID()`, με εναλλακτική `Math.random`.

## 11. Αποκλίσεις από το αρχικό spec

| Αρχικό spec | Τρέχουσα κατάσταση | Λόγος |
| --- | --- | --- |
| Όνομα «WorksheetForge», αρχείο `worksheet-forge.html` | «Σύνταξη φύλλων εργασίας», `index.html` | Αίτημα χρήστη, συμβατότητα με GitHub Pages |
| Μέγεθος < 2 MB | ~2,28 MB (κάτω από το απόλυτο όριο των 4 MB) | Ενσωματωμένες γραμματοσειρές KaTeX και docx.js |
| Όλες οι βιβλιοθήκες σε ένα `<script>` | Ένα `<script>` ανά βιβλιοθήκη | Απομόνωση σφαλμάτων· οι ίδιες σημάνσεις `LIBRARY` |
| Βιβλιοθήκη προτύπων στο localStorage | Αρχεία `.json` σε φάκελο του χρήστη | Αίτημα χρήστη |
| `iframe` απαγορεύεται | Ελεγχόμενες ενσωματώσεις με sandbox. Το iframe φτιάχνεται από την εφαρμογή, όχι από αποθηκευμένο HTML | Αίτημα χρήστη |
| Εξισώσεις στο DOCX ως κείμενο LaTeX | Ως εικόνες, με το LaTeX στο εναλλακτικό κείμενο | Πιστή αναπαραγωγή |
| Κανένα δίκτυο | Δίκτυο μόνο για υπαγόρευση και ενσωματώσεις, προαιρετικά | Αίτημα χρήστη |

Προστέθηκαν επίσης, πέρα από το αρχικό spec:
- εισαγωγή ODT/DOCX, στυλ τελικού φύλλου και λογότυπο,
- στήλες και πλαίσια, λίστες ελέγχου,
- διαδραστικό HTML, φωνητική πληκτρολόγηση,
- καρτέλες ενοτήτων, εισαγωγή αντικειμένων μέσα σε κελιά και πλαίσια,
- αναδίπλωση κειμένου, περικοπή/περιστροφή, ενσωματώσεις,
- λογότυπο στην κεφαλίδα σελίδας,
- διαδικτυακή έκδοση στο claude.ai.
